# Craft Files

Reusable **learning plans** and **Cursor skills** for building apps the steady way.

Edit anything to match your stack or taste. Fork it, rewrite it, make it yours.

**My stack right now:** Laravel · React · Inertia

---

## What's inside

```
learning-plans/   # Checklists you can work through
skills/           # Cursor Agent skills + templates
```

| Path | What it is |
|------|------------|
| [`learning-plans/`](learning-plans/) | Step-by-step plans (Docker, testing, …) |
| [`skills/`](skills/) | Skills you can drop into Cursor and run |

---

## How to use

1. Clone or browse a plan/skill that fits what you're learning.
2. Adapt paths, packages, and stack notes to **your** project.
3. Check items off as you go — or delete phases you don't need.

These files are not a framework. They're craft notes meant to be reshaped.

---

## Skills

Copy a skill folder into your Cursor skills directory (or follow Cursor's skill docs), then ask the agent for that workflow.
